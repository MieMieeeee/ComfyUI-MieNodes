This file is not a system prompt.

The MiniMax H3 Loop user-input enhancer loads one of:

- user_input_enhancer_lock.txt
  A draft the downstream parser accepts as a dialogue board, a draft
  with two or more `speaker：line` rows, or a draft that is a single
  spoken line. Those lines stay byte for byte. The model may only add
  a setting paragraph, positions, and a camera line.
- user_input_enhancer_compose.txt
  Free-form drafts. A colon line inside ordinary prose (`要求：…`,
  `Goal: …`) is this path, not a locked utterance. The model may
  write new dialogue or beats, and must call that writing new.

It then appends the matching section of user_input_enhancer_modes.txt
for the selected reference_mode: t2va, i2va, fl2va, or ref2va.
Those four modes are different downstream implementations. The
enhancer does not infer the mode from the draft.
