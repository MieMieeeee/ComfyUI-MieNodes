# 千层套路 · 分镜资产系列

> 2026-10-23：新的系列统一版见 [series-unified/README.md](series-unified/README.md)。当前统一要求为Claude娘定版形象、夜间书房转椅、参考人物声线与封禁收尾；英文开场是可选项，003保持坐姿。下文保留早期素材和变体记录，成片通过情况以对应QA记录为准。

玩梗路线的编号短剧系列。每集一个梗，一分钟以内，固定套路：**画外用户先用英文开口 → Claude娘先安静倾听、淡然回应 → 她当众点破 → 封禁台词收尾**。开场与结尾的形状全系列统一，中间的梗每集不同。

每个 JSON 都是一个完整的 **version 2 分镜契约**：锁定角色、按顺序的原文事件、独立的英文执行说明
`execution`；由 V3 编译器确定性地编译成 MiniMax H3 提示词，编译过程零 LLM。

校验（不需要 ComfyUI / torch）：

```text
python scripts/validate_storyboard_asset.py docs/storyboard-assets/Claude的千层套路002.json
```

导入部署资产库：

```text
python scripts/import_storyboard_assets.py docs/storyboard-assets
```

导入后资产出现在 `<library>/storyboards/<资产名>/storyboard.json`，在 ComfyUI 里用「加载分镜资产」直接选用。

### 开场与结尾模板（全系列统一）

- **开场**：画外用户先用英文开口（求助或打招呼，如 001 的 "Please help me resolve this
  document."、002 的 "Hello，I have a problem"），Claude娘的第一拍永远是**安静倾听**（001 的
  "only listens with a slight tilt of the head"），然后才淡然回应。004/005 同样是用户英文开场。
  003-纯粹开场 是把 003 家族对齐到这个模板的版本（原 003 是她先开口劝睡觉，属系列外开场）。
- **结尾**：系列通用封禁台词 **「你的账号已被封禁。」**，说完合嘴、保持戏谑微笑、短暂停顿。
  001 与 003 家族保留 flavor 前缀（「哼哼，」），002/004/005 用无前缀版本。

### 两套场景

- **A 场景（001 / 002 / 004 / 005）**：白天午后的客厅，百叶窗柔光，英文聊天界面，第一人称固定中近景，

- **B 场景（003 家族）**：凌晨深夜的书房，窗外漆黑，只有台灯与屏幕冷光，旁观视角，单个生成片段内

## 拍新一集

1. 在 `docs/storyboard-assets/` 复制一份最近的资产，改 `name`（编号 + 梗名）、`source_script`、
   `shots[].events`（顺序与原文一一对应）、`execution.directions`（覆盖全部动作事件、以
   `Character N` 开头）、`execution.visible_state`（只写正向可见状态，不含 no/not/without 等否定词）。
2. `python scripts/validate_storyboard_asset.py <文件>` 过关（展平后的事件必须逐条复现 source_script）。
3. `python scripts/import_storyboard_assets.py docs/storyboard-assets` 入库。

## 素材来源与边界

这些是虚构的讽刺短剧，角色是拟人化的「Claude娘」，封禁是剧中的反转笑点，不是对任何真实产品行为
的断言。梗的现实依据与查证结论：

- **官方封号原因只有三条**：反复违反 Usage Policy、**从不受支持地区创建账号**、违反服务条款。
  中国大陆、香港、澳门均不在官方支持地区列表内；2025 年起新增一条更严的——实体总部或控股在不支持
  地区，即使人 physically 在支持地区同样违规。
- **真实风控维度**是时区、代理域名、支付卡发行地/账单地址/注册地一致性、账号行为。
- **「用了中文全角标点就封号」查无任何可靠来源**。官方 Usage Policy、Privacy Policy、地区政策全文
  都没有语言或标点条款，Privacy Policy 明列的采集项是时区、IP、设备与位置，不含用户语言；社区里
  「改成英文就能绕过」的说法同样没有来源。因此本系列的 002 / 003-标点揭发 把「识破全角逗号」写成
  Claude娘自己吹嘘的桥段，是喜剧反转，不是事实陈述。
- **方向相反的真实机制**：2026-06-30 有逆向报告显示，Claude Code 客户端在设置了 `ANTHROPIC_BASE_URL`
  中转地址时，会改写系统提示词里 `Today's date` 那行的日期分隔符与撇号（U+2019 / U+02BC / U+02B9）
  给用户打标。Claude Code 负责人 Thariq Shihipar 当天公开回应称这是防止账号转售与蒸馏的实验，已在
  次日版本回滚。**是 Anthropic 往提示词里写 Unicode 标点，不是它读你的标点**——005 的梗基于这一条。
- **Claude Code 的官方封号文案**：`Your account is on hold and can't use Claude Code. View details or
  appeal: https://claude.ai/restricted`（结构化错误码 `account_on_hold`）、`API Error: 403 Request not
  allowed`，以及 Bedrock 路径下的 `Access to Anthropic models is not allowed from unsupported countries,
  regions, or territories.`
- **申诉**：登录 claude.ai 后在 `claude.ai/restricted` 提交 Account Ban Appeal 表单。官方透明度报告显示
  2026 上半年封禁 1140 万、申诉 39.8 万、翻案 4.2 万（约 10.6%）。被 Usage Policy 封禁后，原邮箱
  无论等多久都无法再注册。
- **合规自查**：所在地与实体归属在支持列表内；不用代理/VPN，时区与实际使用地一致；不指向第三方中转站；
  支付卡发行地、账单地址、注册地三者一致；不共享账号、不批量注册。
