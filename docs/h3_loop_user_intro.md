## 这条流程在干什么

从一段想法，到一条可连续生成的片子。可以看成三步。

### 1. 你准备什么

- **概念与对白**：谁在画面里、坐哪、说什么。一句话一行最稳。
- **可选：参考图**：用来锁外貌和服装。没有图就纯文生。参考图会带进全片人物，也会带进每一场。
- **节奏 / 时长 / 场数**：节奏管的是语速，不增减场数。时长不填则按语速自动估。场数 `0` = 尽量少切；填了就是你要的场数。
- **可选：先润色**：抽词之前把随手草稿写成规范概念。已经写成「角色：台词」就可以关掉。

### 2. 先听清有没有人在说话

把每一句台词从原文抠出来：**照抄，不改写、不翻译**。已经是「角色：台词」、至少两句时，直接切开，不必再猜；自由散文才会去听。听不清会警告，并改走旁白。跑完能看出本局是对白还是旁白。

| 判断 | 怎么拆场 |
|---|---|
| 有对白 | 场数未填：按说话打包成场。不改词；14 秒内尽量少切；说话人换了也不强行切开。场数填了：按说话量均分到这么多场；比台词还多的场是静默反应镜头（切到听的人，不开口）。 |
| 没有对白 | 按故事拆成场。纯旁白、空镜、动作戏，由模型决定切几刀。 |

### 3. 写成一条连续的分场计划

- **定全片风格与人物**：画风、光线、环境；谁是谁，声音保持同一人。有参考图则锁进人物。短对白（不超过 4 轮、不超过 8 句、没有参考图）风格从场景设定直接裁，不必再生成一次。
- **逐场写画面与声音**：下一场接着上一场的动作。模型只填镜头、表情、环境声；台词由流程用原文拼进这一场，抄进去的会被拿掉。
- **得到分场计划**：每场几秒、说什么、怎么接。交给 H3 循环逐段生成，多场接成一条连续视频。

对白路径的承诺是：**不漏词、不拆词、不改词**。旁白路径没有这条承诺。

## 还值得优化的地方

按收益排列。下面六条已于 2026-09 全部落地（标注 ✅）。

### 1. 台词当数据，不要再让模型抄一遍（收益最大）✅

抽出对白之后，每一句已经是确定的。~~现在仍请模型在每场提示词里「再写一遍」，写错了再重试。~~

已改为：场次结构先把台词锁进格子，模型只填镜头、表情、环境声。漏词 / 拆词从概率问题变成不可能（模型抄的任何台词会被自动剥除，节点用锁定的原文拼上 `<d>` 块），调用也更少。

### 2. 润色和抽词不要两次读同一段话 ✅

规范格式（`角色：台词`，润色器的输出就是它）现在被确定性解析直接识别——抽取调用整个跳过。已经会写规范格式的人天然享受同一条快路。

### 3. 对白用户的默认选项还是旁白向的 ✅

抽出对白后，类别「不指定」自动按对白处理（摄影建议自动跟上），summary 里说明；widget 存量值不变。

### 4. 「快 / 慢」听起来像切镜，实际只管语速 ✅

选项标签改为「快（语速）/ 正常（语速·推荐）/ 慢（语速）」，tooltip 开头写明这是语速控制、对白板不增减场数。旧工作流存的标签仍然兼容。

### 5. 短对白不必走满全套 ✅

对白板不超过 4 轮、不超过 8 句、无参考图时，全片风格直接从场景设定文本裁出，不必再生成一次。

### 6. 对白板 / 旁白板在界面上长得一样 ✅

节点新增第三个输出 `board_kind`（`dialogue` / `narration`），summary 首行同步标注；抽取失败回退旁白时写明「spoken lines NOT preserved」。
