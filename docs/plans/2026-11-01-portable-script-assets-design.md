# 剧本资产可替换契约（2026-11-01）

用户已确认实施。范围：剧本资产契约、生成/保存/加载、编译装配、系统指令与文档测试。角色/场景资产的格式、节点、库实现不变。

## 契约
- 剧本决定角色槽位、台词、动作、出入场、镜头和时间顺序；角色与场景资产可独立、部分接入。
- 每个出镜角色：接入资产时使用资产身份与外观；未接入时使用剧本默认角色设计，未指定则交给模型生成。
- 场景：接入资产时使用资产环境、光照；未接入时使用剧本默认场景与光照，空缺交给模型生成。
- 默认设计必须独立存储并按接线条件编译；不能混入不可替换的表演文字。
- 只给实际接入的出镜角色分配 Picture 编号，场景图紧随其后；无图角色不得引用不存在的图片。
- audio_mode generated/reference 保持现有语义；reference 模式仍要求完整声音参考，不静默改模式。
- 保留 version=2 编号，统一采用新契约并更新活跃旧剧本；台词、事件及顺序不变。不维护旧剧本的混写规则。
